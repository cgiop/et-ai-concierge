# et-ai-concierge

ET AI Concierge for the ET ecosystem.

Backend:
- `python -m backend.app --serve`
- `python -m backend --serve`

Frontend:
- `cd frontend`
- `npm start`

Current product coverage:
- Welcome Concierge with required profile capture and onboarding path
- Financial Life Navigator with portfolio gaps and immediate needs
- Ecosystem cross-sell and alert suggestions
- Services marketplace recommendations across loans, insurance, credit cards, and wealth
